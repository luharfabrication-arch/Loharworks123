# Luhar Construction & Fabrication Website

Official web application for **Luhar Construction & Fabrication** (Over 35 years of engineering excellence in Dehradun, Uttarakhand, and across India).

## 🚀 Key Features

- **24/7 Operations & Direct Contact**: Updated business hours, primary and secondary phone numbers, email, and exact Google Maps location (68 Nala Pani Road, Dehradun, Uttarakhand 248001).
- **Interactive Service Directory & Pricing**: Real photos and details for Civil Construction, Heavy Fabrication, Modular Kitchens, PVC False Ceilings, SS Railings, and Teen Sheds.
- **Public Rating & Review System**: Interactive star rating and customer review section allowing clients to submit feedback directly on the website with instant verification display.
- **Real Photo Portfolio Manager**: High-resolution gallery displaying real projects with category filters and project details.
- **Owner Control Panel**:
  - Securely protected with passcode `Shayanluhar123` (password hidden from public view).
  - Ability to upload real project photos directly from local device to replace default AI placeholder photos.
  - Ability to edit service details, pricing, public reviews, hero banners, and contact information.
  - Dashboard for managing customer site visit bookings.
- **Instant Cost Estimator & WhatsApp Connect**: Integrated quote calculator and floating WhatsApp chat menu.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, Motion
- **Context API**: Persistent local state management with localStorage backup & export capabilities

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
